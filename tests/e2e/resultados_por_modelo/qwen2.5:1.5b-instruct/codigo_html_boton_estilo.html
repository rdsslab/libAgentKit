```html Change Color Button
Click Me
``` In this code, we have created a simple HTML page with a button. The button has a class `button.green` which when clicked, changes to a blue background color and the text color changes to white. When the button loses focus, it changes back to its original color and text color. The `toggleColor` JavaScript function toggles the class of the `button.green` on the button, so its background color changes from blue to green and vice versa.
