# Results Index

Quick index of demo runs, artifacts, and environment.

- **Manifest:** [`index.json`](./index.json)
- **Environment snapshot:** [`environment.json`](./environment.json)
- **Consolidated report:** [`../RESULTS.md`](../RESULTS.md)
- **Detailed per-test results:** `../<test>/results/<model>/`
- **Generated artifacts:** per-test `output/<model>/` folders (and latest copies in `output/`)

Each run JSON includes environment specs, configuration, task duration, token/context metrics, tool/web diagnostics, ground truth, and coherence/validation checks.
